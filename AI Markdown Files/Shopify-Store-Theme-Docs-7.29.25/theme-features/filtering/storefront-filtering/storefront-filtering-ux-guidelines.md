Storefront filtering UX guidelines
==================================

Storefront filtering is an essential component to the customer experience as it helps them find what they're looking for faster, which can help increase conversions for merchants.

The following outlines some key considerations related the filtering experience.

To learn how to implement a basic version of storefront filtering, refer to [Support storefront filtering](https://shopify.dev/docs/storefronts/themes/navigation-search/filtering/storefront-filtering/support-storefront-filtering).

Provide the right interface for each filter type
------------------------------------------------

[Anchor link to section titled "Provide the right interface for each filter type"](https://shopify.dev/docs/storefronts/themes/navigation-search/filtering/storefront-filtering/storefront-filtering-ux#provide-the-right-interface-for-each-filter-type)

There are two filter types:

*   [List](https://shopify.dev/docs/storefronts/themes/navigation-search/filtering/storefront-filtering/storefront-filtering-ux#list)
*   [Price range](https://shopify.dev/docs/storefronts/themes/navigation-search/filtering/storefront-filtering/storefront-filtering-ux#price-range)

### List

[Anchor link to section titled "List"](https://shopify.dev/docs/storefronts/themes/navigation-search/filtering/storefront-filtering/storefront-filtering-ux#list)

It's recommended to use a set of checkbox inputs for filters of type `list` to make it obvious that multiple values can be selected at once.

For example:

![Image 14](https://cdn.shopify.com/shopifycloud/shopify_dev/assets/themes/filters/list-filters-879549b5e22768fc0235f83f7603254fe917d49af9f37be35d2c74a9beb4ac7b.png)

### Price range

[Anchor link to section titled "Price range"](https://shopify.dev/docs/storefronts/themes/navigation-search/filtering/storefront-filtering/storefront-filtering-ux#price-range)

It's recommended to use a dual-handled slider for filters of type `price_range`, however you should also include number input fields for the "start" and "end" values of the range to account for accessibility. You should ensure that the fields number fields have labels, such as "From" and "To", even if they're visually hidden.

For example:

![Image 15](https://cdn.shopify.com/shopifycloud/shopify_dev/assets/themes/filters/range-filter-d38f0f3b5669b63b4e2d5ac7108ca4cf1a6b81d0ec0a690b9683de75eb35dda3.png)

Provide a choice of filter layout
---------------------------------

[Anchor link to section titled "Provide a choice of filter layout"](https://shopify.dev/docs/storefronts/themes/navigation-search/filtering/storefront-filtering/storefront-filtering-ux#provide-a-choice-of-filter-layout)

There are two standard layouts for filtering on larger screens:

*   A [horizontal toolbar](https://shopify.dev/docs/storefronts/themes/navigation-search/filtering/storefront-filtering/storefront-filtering-ux#horizontal-toolbar-filters) above the product list
*   A [vertical sidebar](https://shopify.dev/docs/storefronts/themes/navigation-search/filtering/storefront-filtering/storefront-filtering-ux#vertical-sidebar-filters) to the left of the product list

In order to provide flexibility for varying merchant needs, you should consider providing both layouts as an option behind a theme setting.

### Horizontal toolbar filters

[Anchor link to section titled "Horizontal toolbar filters"](https://shopify.dev/docs/storefronts/themes/navigation-search/filtering/storefront-filtering/storefront-filtering-ux#horizontal-toolbar-filters)

A horizontal toolbar above the product list can provide a compact entry point to both filtering and sorting, but works best for smaller stores that need less than five filters at a time.

For example:

![Image 16](https://cdn.shopify.com/shopifycloud/shopify_dev/assets/themes/filters/horizontal-filtering-9061b4cf911b871f2dab1c8534a5a790b901d2e327744367086d3c4e585faf13.png)

### Vertical sidebar filters

[Anchor link to section titled "Vertical sidebar filters"](https://shopify.dev/docs/storefronts/themes/navigation-search/filtering/storefront-filtering/storefront-filtering-ux#vertical-sidebar-filters)

A vertical sidebar to the left of the product list works best for stores with more than five filters.

For example:

![Image 17](https://cdn.shopify.com/shopifycloud/shopify_dev/assets/themes/filters/vertical-filtering-7628100dfb094d70ff8c93d24124856a93ad1cb2074e145d8a623f2603f9cb33.png)

Provide a clear visual hierarchy
--------------------------------

[Anchor link to section titled "Provide a clear visual hierarchy"](https://shopify.dev/docs/storefronts/themes/navigation-search/filtering/storefront-filtering/storefront-filtering-ux#provide-a-clear-visual-hierarchy)

You should style filters to make relationships clear. For example, the name of each filter group should stand out from its values, and there should be a clear separation between filter groups.

For example:

![Image 18](https://cdn.shopify.com/shopifycloud/shopify_dev/assets/themes/filters/hierarchy-f103253627ff8b94a1f6cf83bfd8d2f1e4b9b04b810579fc74336d80bc4395c7.png)

Avoid dead ends
---------------

[Anchor link to section titled "Avoid dead ends"](https://shopify.dev/docs/storefronts/themes/navigation-search/filtering/storefront-filtering/storefront-filtering-ux#avoid-dead-ends)

Customers shouldn't end up with zero results. As such, you should always show the count of results with each filter value, and disable any values that have zero results.

For example:

![Image 19](https://cdn.shopify.com/shopifycloud/shopify_dev/assets/themes/filters/avoid-dead-ends-0727d0057632d91b7075f2ac4e8d2e4d3444c002c7ff9e544074c2b7ed728232.png)

Show applied filters
--------------------

[Anchor link to section titled "Show applied filters"](https://shopify.dev/docs/storefronts/themes/navigation-search/filtering/storefront-filtering/storefront-filtering-ux#show-applied-filters)

If a customer lands on a page with filters already applied, they need to be able to see which filters have been applied. Similarly, if a customer adds a filter, they need feedback that it applied.

In both of the above scenarios, customers should have an easy way to remove an individual filter, or clear all filters.

For example:

![Image 20](https://cdn.shopify.com/shopifycloud/shopify_dev/assets/themes/filters/applied-filters-05854375d372a4a060f148530913f6d431bf42e8ea8046ede0b329563dc0e57f.png)
Often, filter values are clear enough that applied filter labels can just display the value, such as "Shoe" or "In stock". However, sometimes it may not be clear which filter a value applies to, such as having filters for both "Width" and "Height".

To account for this possiblity, you should add a theme setting to allow merchants to include the filter group name with the filter value.

For example:

![Image 21](https://cdn.shopify.com/shopifycloud/shopify_dev/assets/themes/filters/applied-filters-show-group-9904ab2a1fe6ad544f2215d369044afceecf6addb500d500d9162a2c9ac7a409.png)

Manage filter groups
--------------------

[Anchor link to section titled "Manage filter groups"](https://shopify.dev/docs/storefronts/themes/navigation-search/filtering/storefront-filtering/storefront-filtering-ux#manage-filter-groups)

In vertical sidebars, you should consider collapsing filter groups after the first five. This makes it easier to scan for the desired filter group with minimal scrolling.

For example:

![Image 22](https://cdn.shopify.com/shopifycloud/shopify_dev/assets/themes/filters/manage-groups-7788fc671c8324d8c92b5109139bf31ffe27ac4f5bbfae318a0b7055ebb36052.png)

Manage filter values
--------------------

[Anchor link to section titled "Manage filter values"](https://shopify.dev/docs/storefronts/themes/navigation-search/filtering/storefront-filtering/storefront-filtering-ux#manage-filter-values)

Filter groups can display up to 100 values, so you should truncate the list to 10 values with the option to show more. The first 10 values likely aren't the most relevant, so if possible, you should show the 10 most relevant values.

For example:

![Image 23](https://cdn.shopify.com/shopifycloud/shopify_dev/assets/themes/filters/manage-values-081ba25ef5314f607805e49a164156f02daf2c0d4eeb92bfe97f585ff28ffa95.png)

Optimize for mobile
-------------------

[Anchor link to section titled "Optimize for mobile"](https://shopify.dev/docs/storefronts/themes/navigation-search/filtering/storefront-filtering/storefront-filtering-ux#optimize-for-mobile)

In general, the filter interface on mobile should be moved into a drawer or modal. With that, there are two standard options for surfacing that interface:

*   [A single button](https://shopify.dev/docs/storefronts/themes/navigation-search/filtering/storefront-filtering/storefront-filtering-ux#filter-button)
*   [A horizontally scrolling filter group list](https://shopify.dev/docs/storefronts/themes/navigation-search/filtering/storefront-filtering/storefront-filtering-ux#horizontal-filter-group-list)

### Filter button

[Anchor link to section titled "Filter button"](https://shopify.dev/docs/storefronts/themes/navigation-search/filtering/storefront-filtering/storefront-filtering-ux#filter-button)

With the main filtering interface inside a drawer or modal, you can include a "filter" button to show it:

![Image 24](https://cdn.shopify.com/shopifycloud/shopify_dev/assets/themes/filters/mobile-filter-button-053fd70a45c24cc9ce90e755ac414977e32191fc7195d844b540ddd18d5f9c37.png)

### Horizontal filter group list

[Anchor link to section titled "Horizontal filter group list"](https://shopify.dev/docs/storefronts/themes/navigation-search/filtering/storefront-filtering/storefront-filtering-ux#horizontal-filter-group-list)

With the main filtering interface inside a drawer or modal, you can provide quick access to filter groups with a horizontally scrolling list of filter groups, where each group will open the associated filters in a modal. You should also consider having a "filter" button like the previous example as a fallback:

![Image 25](https://cdn.shopify.com/shopifycloud/shopify_dev/assets/themes/filters/mobile-filter-list-46950f8567fd11ab54a9862975dabee03f93ac2bae87ecd317752c6a1b254867.png)

Use progressive enhancement
---------------------------

[Anchor link to section titled "Use progressive enhancement"](https://shopify.dev/docs/storefronts/themes/navigation-search/filtering/storefront-filtering/storefront-filtering-ux#use-progressive-enhancement)

In order to build lean, fast themes, you should implement as much as you can without JavaScript. For filters, this means using links, or forms with manual submit buttons, to apply selected filters.

JavaScript can be layered onto the basic implementation to enhance the experience, such as live-updating the product grid.

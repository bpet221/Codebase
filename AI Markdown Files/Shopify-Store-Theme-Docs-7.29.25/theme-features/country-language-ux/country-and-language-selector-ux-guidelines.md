Country and language selector UX guidelines
===========================================

There are two main considerations for including country and language selectors in your theme:

*   [Where to place the selectors](https://shopify.dev/docs/storefronts/themes/markets/country-language-ux#selector-placement)
*   [How to style the selectors](https://shopify.dev/docs/storefronts/themes/markets/country-language-ux#selector-styling)

Selector placement
------------------

[Anchor link to section titled "Selector placement"](https://shopify.dev/docs/storefronts/themes/markets/country-language-ux#selector-placement)

The following are the main locations you should place country and language selectors:

*   [The footer](https://shopify.dev/docs/storefronts/themes/markets/country-language-ux#the-footer)
*   [Near the customer account links](https://shopify.dev/docs/storefronts/themes/markets/country-language-ux#near-the-customer-account-links)
*   [Near the cart](https://shopify.dev/docs/storefronts/themes/markets/country-language-ux#near-the-cart)
*   [Inside a navigation drawer](https://shopify.dev/docs/storefronts/themes/markets/country-language-ux#inside-a-navigation-drawer)

Regardless of placement, if you have both country and language selectors, then they should always be placed together.

#### Note

The example images below only show a country selector, however the same guidelines apply to the language selector.

### The footer

[Anchor link to section titled "The footer"](https://shopify.dev/docs/storefronts/themes/markets/country-language-ux#the-footer)

If you place the selector in the footer, then it should be placed at the top of the sub-footer content, separate from the footer navigation links:

![Image 16](https://cdn.shopify.com/shopifycloud/shopify_dev/assets/themes/internationalization/ux/footer-localization-desktop-02fbc15fd9a97a5b68f65c8cfec91226178f12574e33471f90cf2e21c00f5f4d.png)![Image 17](https://cdn.shopify.com/shopifycloud/shopify_dev/assets/themes/internationalization/ux/footer-localization-mobile-b5f74f5d6f8819635f3c3ca41bc4bebec254e947262f15fa2024218f56efa466.png)

### Near the customer account links

### Near the cart

Selector styling
----------------

[Anchor link to section titled "Selector styling"](https://shopify.dev/docs/storefronts/themes/markets/country-language-ux#selector-styling)

Custom selectors should borrow the theme's styling for dropdown selectors as much as possible, including typography, colors, height, and hover states.

You can create a custom component for your selector instead of using a native `select` element. When building a custom selector, you should implement it as a popover rather than a modal, since a modal can be excessive for cases where only a few options are enabled:

![Image 28](https://cdn.shopify.com/shopifycloud/shopify_dev/assets/themes/internationalization/ux/localization-select-popover-569947c2922fc6ccf404fb7317de7fca757d0881741fc72d7219f9e20563c624.png)
The menu's default hover, focused, selected, and pressed states should match your theme's link patterns. The menu's width should expand to fit its content so that longer strings don't wrap, however, the menu display shouldn't extend beyond the viewport.

### Country and currency format

[Anchor link to section titled "Country and currency format"](https://shopify.dev/docs/storefronts/themes/markets/country-language-ux#country-and-currency-format)

Your selector should include the full country name and include the currency code beside the currency symbol. For example, United States (USD $) and United Kingdom (GBP £).

![Image 29: Example of country and currency selector display](https://cdn.shopify.com/shopifycloud/shopify_dev/assets/themes/internationalization/ux/country-selector-ux-example-cbbd427cab157e03aa24e9076883cd408ee5b3c8fc803bed252a37b919a524d3.png)

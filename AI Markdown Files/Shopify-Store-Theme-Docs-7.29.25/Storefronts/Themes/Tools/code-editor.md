The code editor
===============

The [code editor](http://shopify.com/admin/themes/current) lets you view and edit your theme’s code directly in the Shopify admin.

![Image 11: A browser window showing the theme code editor in the Shopify admin](https://shopify.dev/assets/themes/code-editor/code-editor-79094c930364b62cbfc4b97b34bd20c61297e07f1548407e41f04f690fc3301f.png)

Access the code editor
----------------------

[Anchor link to section titled "Access the code editor"](https://shopify.dev/docs/storefronts/themes/tools/code-editor#access-the-code-editor)

 Desktop  Mobile 

1.   From your Shopify admin, go to **Online Store**>**Themes**.

2.   Find the theme that you want to edit, and then click **...**>**Edit code**.

1.   From the [Shopify app](https://www.shopify.com/install/detect), tap **Store**.

2.   In the **Sales channels** section, tap **Online Store**.

3.   Tap **Manage all themes**.

4.   Find the theme that you want to edit, and then tap **...**>**Edit code**.

Navigate the code editor
------------------------

[Anchor link to section titled "Navigate the code editor"](https://shopify.dev/docs/storefronts/themes/tools/code-editor#navigate-the-code-editor)

The code editor shows theme files in a directory on the left and an editing area on the right. Click a file to open it. You can open and edit multiple files at once.

Add theme files
---------------

[Anchor link to section titled "Add theme files"](https://shopify.dev/docs/storefronts/themes/tools/code-editor#add-theme-files)

To add a file, select a folder, click **New file**, and enter the file name. You can also right-click a folder to add a file.

![Image 12: A partial code editor showing new file creation UI](https://shopify.dev/assets/themes/code-editor/new-file-041ac355742d2ff06b9f7f5f2765a1d8790a42263d566abe16582faadcb657c0.png)

Update theme files
------------------

[Anchor link to section titled "Update theme files"](https://shopify.dev/docs/storefronts/themes/tools/code-editor#update-theme-files)

When you edit a file, a dot appears next to the tab name to show unsaved changes. Click **Save** in the upper-right corner to save your changes.

![Image 13: A partial code editor showing an unsaved file next to the save button](https://shopify.dev/assets/themes/code-editor/save-file-ed40ab0496dda0bf1f8568d3be9fc6d0e193b3955cfa434b9fc3d49cbbf2447f.png)

#### Tip

Use `Cmd + S` (Mac) or `Ctrl + S` (Windows/Linux) to save changes.

### Rename files

[Anchor link to section titled "Rename files"](https://shopify.dev/docs/storefronts/themes/tools/code-editor#rename-files)

Right-click a file and select **Rename...** to rename it.

![Image 14: The option to rename a file in the code editor](https://shopify.dev/assets/themes/code-editor/rename-file-5dc90cfea2be285ffcbd0361b179d27c2b06afedd199395c2242faaef64fafdd.png)

### Track file changes

[Anchor link to section titled "Track file changes"](https://shopify.dev/docs/storefronts/themes/tools/code-editor#track-file-changes)

You can also view past versions of any Liquid file. Find previous versions of the current file in the **Timeline** panel at the bottom right.

To revert changes, select an earlier version, review the differences, and click **Revert contents** in the upper-right corner.

![Image 15: A code editor window displaying previous file versions and the code differences between the current and the past version](https://shopify.dev/assets/themes/code-editor/version-control-84ae0afbdee9495fc9a96a27583e9d43124486319ccc4e5bda21f00c0c213b21.png)

Delete theme files
------------------

[Anchor link to section titled "Delete theme files"](https://shopify.dev/docs/storefronts/themes/tools/code-editor#delete-theme-files)

To permanently delete a file, right-click it and select **Delete permanently**.

![Image 16: A partial code editor showing the option to delete a file](https://shopify.dev/assets/themes/code-editor/delete-file-1184134fdae42ebaa5e34b40f0ea11fdb86e3429275b34590f5aa8695b79b616.png)

Format theme code
-----------------

[Anchor link to section titled "Format theme code"](https://shopify.dev/docs/storefronts/themes/tools/code-editor#format-theme-code)

To fix code indentation, open the Command Palette with `Cmd + Shift + P` (Mac) or `Ctrl + Shift + P` (Windows/Linux), type `format`, and select **Format document**.

![Image 17: Command palette with the code formatting option selected](https://shopify.dev/assets/themes/code-editor/format-file-4410c6550c43972923519e36e444af020eabe470c968f52c700cfb53768ecc3f.png)

#### Tip

Configure formatting options like auto-format on paste or save in settings. Click the cogwheel icon in the bottom left, select **Settings**, and search for `format`.

Review code
-----------

[Anchor link to section titled "Review code"](https://shopify.dev/docs/storefronts/themes/tools/code-editor#review-code)

The code editor includes the [Theme Check](https://shopify.dev/docs/storefronts/themes/tools/theme-check) linter for Liquid and JSON files. It helps you catch errors and follow Shopify theme and Liquid best practices.

See the [Theme Check reference](https://shopify.dev/docs/storefronts/themes/tools/theme-check/checks) for available checks.

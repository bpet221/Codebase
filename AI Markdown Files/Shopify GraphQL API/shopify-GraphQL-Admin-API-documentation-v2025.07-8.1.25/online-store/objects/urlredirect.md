Url Redirect
============

object

Requires `read_online_store_navigation` access scope.

The URL redirect for the online store.

[Anchor to Fields](https://shopify.dev/docs/api/admin-graphql/latest/objects/urlredirect#fields)Fields
------------------------------------------------------------------------------------------------------

[Anchor to id](https://shopify.dev/docs/api/admin-graphql/latest/objects/urlredirect#field-UrlRedirect.fields.id)id

•[ID!](https://shopify.dev/docs/api/admin-graphql/latest/scalars/ID)

non-null

The ID of the URL redirect.

[Anchor to path](https://shopify.dev/docs/api/admin-graphql/latest/objects/urlredirect#field-UrlRedirect.fields.path)path

•[String!](https://shopify.dev/docs/api/admin-graphql/latest/scalars/String)

non-null

The old path to be redirected from. When the user visits this path, they will be redirected to the target location.

[Anchor to target](https://shopify.dev/docs/api/admin-graphql/latest/objects/urlredirect#field-UrlRedirect.fields.target)target

•[String!](https://shopify.dev/docs/api/admin-graphql/latest/scalars/String)

non-null

The target location where the user will be redirected to.

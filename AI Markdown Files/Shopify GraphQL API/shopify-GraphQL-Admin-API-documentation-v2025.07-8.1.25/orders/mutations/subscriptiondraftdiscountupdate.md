subscription Draft Discount Update
==================================

mutation

Requires `write_own_subscription_contracts` access scope. Also: The user must have manage_orders_information permission.

Updates a subscription discount on a subscription draft.

[Anchor to Arguments](https://shopify.dev/docs/api/admin-graphql/latest/mutations/subscriptiondraftdiscountupdate#arguments)
